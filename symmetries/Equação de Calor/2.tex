\subsection{Outro Grupo de Transformação}

Sendo o seguinte grupo de transformações $t^* = t$, $x^* = x + 2\e t$ e $u^* = u \exp(- \e x - \e^2 t)$, e aplicando a regra da cadeia nas transformações, encontra-se que:
%
%
\begin{eqnarray}
\deli{^2}{{x^*}^2} &=& \deli{^2}{x^2} \\
\deli{}{t^*} &=& -2\e \deli{}{x} + \deli{}{t}
\end{eqnarray}
%
%
Para simplificar os cálculos, serão utilizadas as seguintes notações: $f(x,t) = e^{-(\e x + \e^2 t)}$, de forma que $f_t = - \e^2 f$, $f_x = \e f$ e $f_{xx} = \e^2 f$. Para a notação de derivadas, tem-se que, $\partial_{t^*} = -2\e\partial_x + \partial_t$ e que $\partial_{x^*x^*} = \partial_{xx}$. Aplicando o $\partial_{t^*} - \partial_{x^*x^*}$ na função $u^* = u e^{-(\e x + \e^2 t)} = uf$, tem-se que:
%
%
\begin{eqnarray}
\nonumber (\partial_{t^*} - \partial_{x^*x^*})(uf) &=& (-2\e\partial_x + \partial_t - \partial_{xx})(uf) \\
\nonumber &=& -2\e(u_x f + u f_x) + (u_t f + u f_t) - (u_{xx} f + 2 u_x f_x + u f_{xx})\\
\nonumber  &=& -2\e(u_x - \e u)f + (u_t  - \e^2 u)f - (u_{xx} - 2\e u_x  + \e^2 u)f\\
\nonumber  &=& f(u_t - u_{xx}) = 0
\end{eqnarray}


\subsection{Gerador Infinitesimal e Grupos}

As transformações $t^* = t$, $x^* = x + 2\e t$ e $u^* = u e^{-(\e x + \e^2 t)}$ formam um grupo, com a lei de coposição $\phi(a,b) = a + b$. De fato, tem-se que:
%
%
\begin{eqnarray}
\nonumber t^{**} &=& t^* = t\\
\nonumber x^{**} &=& x^* + 2\delta t^* = x + 2\phi t\\
\nonumber u^{**} &=& u^* e^{-(\delta x^* + \delta^2 t^*)} = u e^{-(\phi x + \phi^2 t)}\\
\nonumber \phi   &=& \phi(\e,\delta) = \e + \delta
\end{eqnarray}
%
%
O gerador infinitesimal desse grupo de transformações é dado por:
%
%
\begin{eqnarray}
\nonumber X &=& \xi_1 \deli{}{t} + \xi_2\deli{}{t} + \eta\deli{}{u} \\
          X &=& 2t\deli{}{t} - xu\deli{}{u}
\end{eqnarray}
%
%
Lembrando que:
%
%
\[\xi_1(t,x,u) = \deri{t^*}{\e}\Big|_{\e = 0} \qquad \xi_2(t,x,u) = \deri{x^*}{\e}\Big|_{\e = 0} \qquad \eta(t,x,u) = \deri{u^*}{\e}\Big|_{\e = 0}\]
